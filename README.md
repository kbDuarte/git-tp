# Atividade de Git e GitHub

Repositório que estou usando na atividade de Gestão de Código-Fonte da faculdade.

Fiz uma página simples com HTML, CSS e JavaScript para praticar as mudanças pelo GitHub. Durante a atividade, estou trabalhando com commits, branches e pull requests.

## Arquivos

- `index.html`: conteúdo da página.
- `style.css`: estilos.
- `script.js`: atualiza o ano no rodapé.
- `docs/`: anotações sobre a atividade e as evidências.
- `evidencias/`: pasta para colocar as capturas de tela.

## Como abrir

É só abrir o arquivo `index.html` no navegador. Não precisa instalar nada para ver a página.
