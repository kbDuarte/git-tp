# Evidências da atividade

Vou usar esta lista para não esquecer as capturas que preciso tirar durante a atividade. Os prints devem ser das telas reais do GitHub ou do terminal.

- [ ] Repositório criado e arquivos publicados.
- [ ] Branches criadas para as alterações.
- [ ] Histórico de commits.
- [ ] Clone do repositório e comando `git remote -v`.
- [ ] Atualização com `git fetch` e `git pull`.
- [ ] Alteração enviada para o repositório.
- [ ] Conflito reproduzido e resolvido.
- [ ] Pull Request e revisão.
- [ ] Exemplo de `git revert`.
- [ ] Página aberta no navegador depois das alterações.

Sugestão de nomes para os arquivos: `01-repositorio.png`, `02-branches.png`, `03-commits.png` e assim por diante.

Ainda preciso executar e registrar as etapas acima antes de marcar a atividade como completa. Se alguma parte for feita de um jeito diferente do roteiro, vou anotar isso no registro da atividade.
